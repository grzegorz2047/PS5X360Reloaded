#
# Format: "[section]" lines, then "<Portuguese key> = <text>" lines. As in the language files,
# "\s" is a space (needed at the start or end of a text), "\n" a new line, "\\" a backslash;
# spaces inside a text may be written as they are. Lines starting with "#" are comments.
# printf specifiers (%d, %08X) and edge spaces must be kept: the texts are joined with data.
#
# [english]  English for Portuguese keys that have English nowhere else: not in en.txt (the
#            official package's, merged with the fork's overrides), not in Tr's built-in table,
#            not in a FramegenText or CoreUiText English. Until fix 25 these showed in
#            Portuguese to an English user (and to any language whose file lacked them).
# [keys]     The English key of a Portuguese key when it is not just its English: the context
#            keys of collisions. Two Portuguese keys with the same English but different
#            translations (gender, number, or a different word) cannot share one English key,
#            so one keeps the plain English and the others get "<English>||<context>". Only the
#            part before "||" is shown when no language file has the key. rekey.py fails on any
#            collision not resolved here.
# [<code>]   Translations, for a language code (es, es-419, pt, de, fr, it, ja, ko, nl, pl, ru, tr,
#            zh-Hans, zh-Hant), of keys that are in no language file: fix 22's "Rede" row and
#            the guide's "opção"/"opções" counter. They follow each file's own words (Opções,
#            Rede desligada, the jogo/jogos counter: Polish and Russian use the plural form for
#            five and more, Japanese and Korean a counter, Turkish no plural after a number).
# [added <code>]  Translations, for a language code (pt-BR and the others, not en: the key is
#            the English), of English keys that fixes after fix 25 add: "<English key> =
#            <translation>". Fixes after fix 25 are written against English keys (Tr("...") in
#            English); tools/check-english-source.py fails until pt-BR and the 13 full files
#            translate each new key here.

With a phone as the Kinect, the phone can also send a small picture from its camera for games that show the camera (replays, photos). It goes only to this console, and the emulator keeps it in memory only, never on a drive; a game may still keep photos of its own in its saves. It also needs Camera picture for the game on the phone page. Smooths the jagged edges of the game's picture before it is scaled to the screen. FXAA: light, keeps text sharp. FXAA Extreme: smoother edges, a slightly softer picture. Vulkan only; it costs little. SMAA 1x: cleaner edges than FXAA with less blur, a little heavier. = Adoucit les bords crénelés de l'image du jeu avant sa mise à l'échelle à l'écran. FXAA : léger, garde le texte net. FXAA Extrême : bords plus lisses, image un peu plus douce. Vulkan uniquement ; coûte peu. SMAA 1x : bords plus nets qu'avec FXAA et moins de flou, un peu plus exigeant.

Shows the game's new pictures at most this many times a second, each for the same time, for an even motion on screen. Automatic: as before. = 每秒最多顯示這麼多次遊戲的新畫面，每個畫面顯示相同的時間，讓畫面動作更平順。遊戲本身照常執行（速度、聲音和模擬的畫面更新率都不變），比上限慢的遊戲會照原樣顯示。40 需要 120 Hz 輸出（幀生成輸出：最高 120 Hz）；在 60 Hz 下會顯示每個畫面。開啟幀生成時不起作用。自動：與以前相同。
