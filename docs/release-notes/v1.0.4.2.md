## PS5X360Reloaded v1.0.4.2

A hotfix for v1.0.4.1, built from source the same way. The home screen shows `PS5X360Reloaded v1.0.4.2`. It is installed and updated like v1.0.4.1 (`PPSA83600.ffpkg`, `.ffpfsc` or `.zip`; the whole `PPSA83600` folder, not `eboot.bin` alone). Its `contentVersion` is `01.004.002`, so the console sees v1.0.4.1 as an older install.

**How to read the status tags below:**
- `[console]`: confirmed on PS5 on a test build; the build is named.
- `[host tests]`: verified by tests on a computer (`tools/check-*`, run in CI), not confirmed on the console.

### Fixes
- **Brian Lara International Cricket 2007 (`434D07D8`) no longer crashes at start** (fix 97, issue #16):
  - Before: about five seconds after the start, the emulator crashed with a read fault at `0x20`. The game sets a timer that calls back into one of its own threads. When the timer fired, the emulator tried to hand that callback over from a helper thread of its own, which on the PS5 lacked what it needed to do so.
  - The callback now goes through a small kernel thread that can deliver it, and is skipped if the game's thread has already ended. Other games that use such timers benefit too.
  - `[console, 1.0.5_candidate_62 with fix 97: the game reached gameplay at about 53 FPS; host tests]`

### Known limitations
- Everything listed for v1.0.4 and v1.0.4.1 still applies.
- Tekken Tag Tournament 2 (`4E4D0859`): some costume colours are wrong (issue #14); not fixed in this hotfix.
  Workaround: in the game's settings, set "Image readback by the game" to "Full (slow)" before starting it.
