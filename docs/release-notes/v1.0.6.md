## TrinityX360 v1.0.6

The fourth release built from source, and the first under the app's new name: **TrinityX360**
(until v1.0.5 it was called PS5X360Reloaded). The home screen shows `TrinityX360 v1.0.6`. It is
installed and updated like v1.0.5 (`PPSA83600.ffpkg`, `.ffpfsc` or `.zip`; the whole `PPSA83600`
folder, not `eboot.bin` alone). Its `contentVersion` is `01.006.000`, so the console sees v1.0.5
and older as older installs.

TrinityX360 is based on [PS5X360](https://github.com/BrinooTk/PS5X360) by BrinooTk and on
[Xenia Canary](https://github.com/xenia-canary/xenia-canary). Trinity is the name of the Xbox 360 S
motherboard.

**How to read the status tags below:**
- `[console]`: confirmed on PS5 on a test build; the build is named where it matters.
- `[host tests]`: verified by tests on a computer (`tools/check-*`, run in CI), not confirmed on the console.

### New name: TrinityX360

- **Only the name changed** `[host tests]`: the home screen tile, its icon and backgrounds, the
  label on the home screen, the window, the guide, notifications, the web settings and phone
  camera pages, and the logs ZIP say TrinityX360. The homebrew catalog does not list an app whose
  name contains the name of an app it already lists (PS5X360), so the fork needed a name of its own.
- **Your install, saves and settings carry over** `[host tests]`: the title id stays `PPSA83600`
  and the data folder `/data/homebrew/PPSA83600`, so v1.0.6 installs over PS5X360Reloaded as any
  update does, and the console keeps one tile. Settings in `/download0` stay too.
- **Saves on other drives stay where they are** `[host tests]`: the folder on each M.2 or USB
  drive keeps its name, `<drive>/PS5X360Reloaded/saves` (or below the drive's `xbox360` or
  `homebrew` folder). Do not rename it.
- **Forwarder tiles keep working**: they start `PPSA83600`, which did not change.
- **Phone camera (Kinect)**: a certificate the PS5 made before v1.0.6 keeps the name
  "PS5X360Reloaded Kinect camera" and still works; one made from now on is called
  "TrinityX360 Kinect camera". The phone page's steps name both.
- New icon and backgrounds: three interlocking rings (the "trinity") in light grey, blue and
  green on a dark navy background, with the name TrinityX360, in place of the official art with
  a "RELOADED" plate. The home screen's pictures that showed the PS5X360 logo (the "Online" tile,
  the "Original dashboard" tile and the orb in the corner) show the rings too.
