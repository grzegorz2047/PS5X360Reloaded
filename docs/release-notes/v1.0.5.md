## PS5X360Reloaded v1.0.5

The third release built from source, and the largest so far. The home screen shows `PS5X360Reloaded v1.0.5`. It is installed and updated like v1.0.4.2 (`PPSA83600.ffpkg`, `.ffpfsc` or `.zip`; the whole `PPSA83600` folder, not `eboot.bin` alone). Its `contentVersion` is `01.005.000`, so the console sees v1.0.4, v1.0.4.1 and v1.0.4.2 as older installs.

**How to read the status tags below:**
- `[console]`: confirmed on PS5 on a test build; the build is named where it matters.
- `[host tests]`: verified by tests on a computer (`tools/check-*`, run in CI), not confirmed on the console.

### Games
- **Battlefield 3: the HD content installs and is used** (issue #21, fix 101) `[console]`: "Install HD content" put the pack on a drive the game then refused ("Device Not Allowed"), and after the game's own restart it found its content folder empty. Extended storage now counts as a hard drive, a game's own content is created where it asked, and the pack is found after the restart and after the swap to Disc 2.
- **Kinect Sports (`4D5308C9`) is playable with a phone as the sensor** (issue #15; fixes 90, 99, 99b, 106–108, 113, 118, 119, 131) `[console]`: it no longer stops while loading, on its title screen, at "Pick main player" or after a signed-in profile is picked; the player's avatar gets a body shaped by the profile's settings; a lost player can get back in (issue #23); and the replay can show the phone's camera picture (optional).
- **The Sims 3 (`454108E2`)** `[console]`:
  - Loads a saved game much faster: the disc's file sector answers are now real ones, and the log is no longer flooded (fix 121).
  - Live mode runs at about 19–20 FPS instead of about 10 (fixes 123, 125).
  - The Sims' portraits and clothes are drawn correctly (preset with readback Fast, fix 122).
  - The on-screen keyboard works for the saved game's name (fix 114).
- **Dragon Age II (`4541090B`)** `[console]`: with the game language on "Automatic", a Polish (or Russian, Korean, Chinese, Dutch, Turkish) console now gets the game in that language (fix 132); the picture of a new save in "Load Game" is correct (preset, fix 135).
- **Grand Theft Auto IV, Red Dead Redemption, Modern Warfare 2: faster** (fixes 102–105, 110, 111, 116, 120, 133) `[console]`: fewer GPU waits and less GPU-thread work per draw; for example GTA IV's city at about 45–58 FPS.
- **Games no longer stutter when they create or delete files** (fix 129) `[console, Kinect Sports replays: 17–37 → 55–60 FPS]`.
- **Pro Evolution Soccer 6** no longer runs too slowly with VSync on (fix 116) `[console]`.
- **Tekken Tag Tournament 2**: costume colours are correct with the fast resolve readback (issue #14, fix 91) `[console]`.
- **Optimized video memory** is on by default for Modern Warfare 2 and Red Dead Redemption (fix 95) `[console]`.

### Library, DLC and the guide
- **Game groups** (issue #40; fixes 112–112f) `[console]`: a folder of games in a game folder is one tile with a cover mosaic; a folder with one game stays a plain tile; title updates and DLC are never library entries; original Xbox discs are hidden; the same game on two drives is one tile.
- **Multi-disc games are one library entry** (fix 89) `[console]`.
- **DLC tab: remove a package, and turn one off and on** (issue #22; fix 109) `[console]`, but not while a game is running.
- **The guide** (fixes 115–115e) `[console]`: "Restart game" (issue #33); a per-game volume and "Mute game audio" (issue #34); the game's name in the header; tabs with L1/R1; "Measure performance" opens the Performance page.
- **On-screen keyboard for games** (fixes 114, 114b) `[console]`, in the game's own input mode.
- **The dark theme is the default** (fix 98) `[console]`.

### Test option
- **Resolution scale 2x** (issue #38; fixes 117–117k) `[console]`: a per-game option, off by default (1x). Tested at 2x in Tekken Tag Tournament 2, Battlefield 3, GTA IV and Red Dead Redemption: sharper, with memory kept in check. Red Dead Redemption at 2x is sharp but runs at about 20–30 FPS instead of 30.

### For bug reports
- **Logs for a bug report** (Settings, System; fixes 93–93i) `[console]`: collects the logs a report needs.
- More diagnostics in the 30-second performance summary (fixes 73–75, 77–79, 81, 88, 96, 128, 130) `[console]`.

### Tested on the console
`1.0.5_candidate_89`, the code of this release, with no hang or stall in any run:
- **Library:** the Kinect group with both games; Halo CE and Halo Reach on two drives as one tile each; the original Xbox Halo 2 copies left out; 32 games found.
- **Red Dead Redemption at 2x:** about 29 FPS, memory in check.
- **Tekken Tag Tournament 2 at 2x:** about 58 FPS.
- **Battlefield 3 at 2x with the HD pack:** started and played from Disc 1 at about 23–24 FPS.
- **The guide in Battlefield 3:** mute on and off; the game's volume at 75%, 50% and 25%.
- **Dragon Age II:** Polish with "Automatic"; the save picture with the preset.
- **The Sims 3:** about 37–42 FPS.
- **Virtua Tennis 3:** players visible in four of five runs.
- **Every game:** back to the launcher from the guide.

Checked on earlier test builds with the same code for those parts: Battlefield 3's swap to Disc 2 with the HD pack (`1.0.5_candidate_65`); Kinect Sports (`1.0.5_candidate_81` and `_85`); "Restart game" in the guide (`1.0.5_candidate_68`).

### Known limitations
- Everything listed for v1.0.4 still applies.
- **Virtua Tennis 3 (`534507E1`)**: the players show in most matches, but in one of five test runs they were invisible (issue #17 stays open).
- **Battlefield 3**: brief black squares near smoke in the carrier-deck intro, at 1x and 2x.
- **Kinect Sports**: the replay preview with the phone's camera picture still does not look smooth.
- **Red Dead Redemption at 2x**: about 20–30 FPS instead of 30.
