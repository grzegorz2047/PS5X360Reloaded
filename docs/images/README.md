# GitHub presentation assets

Created with the built-in `image_gen` tool. These are decorative branding and an installation illustration, not emulator screenshots.

## banner.png

Since 1.0.6 (the rename to TrinityX360) the banner is drawn by `tools/source-1.0.2/package-art/make_art.py` (on the release branches) (`--banner`), in the style of the package art: the name "TrinityX360" (white and green) and "Xbox 360 emulation on PlayStation 5" in Noto Sans (`assets/fonts`, SIL Open Font License) on a navy gradient, and the three interlocking rings of the app's icon. No official logos.

Until 1.0.5 it was a generated image (prompt: wide 3:1 GitHub README banner for PS5X360; graphite background, emerald light trails, an original translucent cube and two interlocking luminous rings, subtle circuits) with a red "RELOADED" plate over the name.

## installation.png

Prompt: wide editorial installation diagram on graphite with emerald accents and silver type. Headline “From download to your library”. Four numbered steps: “01 DOWNLOAD — Get the release ZIP”, “02 COPY — Copy PPSA50011 via FTP”, “03 ADD GAMES — One folder per game”, “04 LAUNCH — Open PS5X360”. Original archive, folder, generic console and controller icons. No game artwork, official logos, fake screenshots or performance claims.

For PS5X360Reloaded (v1.0.3) two captions were re-lettered in Segoe UI: “Copy PPSA83600 via FTP” and “Open PS5X360Reloaded”. For TrinityX360 (1.0.6) the last one was re-lettered in Noto Sans Regular: “Open TrinityX360”.
